# Official openOMSI 0.2.50 Mac dependency cache

This generic recipe builds public libraries for the MIT-licensed official openOMSI 0.2.50 source on standard Apple Silicon and Intel Mac runners. It exports dependencies with their corresponding public sources and licenses. It contains no private PST client source, addons, user content, credentials or simulator executable.

Official source: https://github.com/openOMSI-org/openOMSI/tree/8e9a6139ac7ba776325bd212864c3f37824b9cd3
